# Getting help

- **Docs:** [sealmesh.dev/docs](https://sealmesh.dev/docs/) — install, configuration, the CLI reference, and the [known limitations](https://sealmesh.dev/docs/status/).
- **Questions:** [GitHub Discussions](https://github.com/SealMesh/sealmesh/discussions).
- **Bugs and feature requests:** [issues](https://github.com/SealMesh/sealmesh/issues/new/choose).
- **Security problems:** never in public — see [SECURITY.md](SECURITY.md).

Sealmesh is an early preview maintained in spare time. There is no paid
support yet; replies are best effort.
